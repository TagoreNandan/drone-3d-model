# apps/server — GCS backend

Go + Echo HTTP API for the Ground Control Station. Connects to TimescaleDB via pgx, and is meant to ingest MAVLink telemetry and serve it to the frontend over REST + WebSocket.

## Stack

- [Echo](https://echo.labstack.com/) v4 — HTTP router/middleware
- [pgx/v5](https://github.com/jackc/pgx) — Postgres driver (pool-based)
- [sqlc](https://sqlc.dev/) — generates typed Go from `sql/queries/*.sql` (not yet run — see below)
- [gorilla/websocket](https://github.com/gorilla/websocket) — realtime hub (`internal/realtime`)
- [zap](https://github.com/uber-go/zap) — structured logging
- [swaggo/swag](https://github.com/swaggo/swag) + [echo-swagger](https://github.com/swaggo/echo-swagger) — OpenAPI docs generated from handler annotations

## Directory Map

```text
apps/server/
├── cmd/server/main.go       # Entrypoint: config, logger, DB pool, Echo routes
├── internal/
│   ├── database/            # pgx pool wrapper
│   ├── db/                  # sqlc-generated queries + models (DO NOT EDIT)
│   ├── pgutil/               # pgtype <-> plain Go conversions shared by DTOs
│   ├── modules/
│   │   ├── vehicles/        # controller.go, service.go, dto.go
│   │   ├── missions/        # controller.go, service.go, dto.go
│   │   ├── telemetry/       # controller.go, service.go, dto.go
│   │   └── alerts/          # controller.go, service.go, dto.go
│   ├── mavlink/              # MAVLink session + custom TUNNEL decoding — STUBS ONLY
│   └── realtime/             # WebSocket hub — implemented, not yet wired to a route
├── docs/                    # Generated by `swag init` — do not hand-edit, see docs/README.md
├── sql/
│   ├── schema/001_schema.sql # Domain schema: vehicles, missions, telemetry_frames, alerts
│   └── queries/*.sql         # sqlc query annotations
├── sqlc.yaml                # sqlc config (out: internal/db)
├── go.mod / go.sum
├── .env / .env.example
└── .gitignore
```

Every domain module under `internal/modules/` follows the same strict three-file layout:

- `dto.go` — request/response structs exposed over JSON (never the raw sqlc/pgtype types)
- `service.go` — business logic; wraps `*db.Queries`, converts to/from DTOs via `internal/pgutil`
- `controller.go` — Echo handlers + swagger annotations; only calls into `service.go`, no SQL or pgtype code

## Running

```sh
go mod tidy
go run cmd/server/main.go
```

Requires `DATABASE_URL` pointing at a reachable Postgres/TimescaleDB instance (see `.env.example`; the root `docker-compose.yml` + `./run.sh` handle this). Fails fast (`logger.Fatal`) if the DB isn't reachable at startup.

Env vars (`.env`):

| Var | Default | Notes |
|---|---|---|
| `HOST` | `0.0.0.0` | bind address |
| `PORT` | `8080` | HTTP port |
| `DATABASE_URL` | — | required; `postgres://gcs:gcs@localhost:5433/gcs?sslmode=disable` locally (port 5433, see root README) |
| `GRPC_PORT` | `50051` | defined but unused — no gRPC server exists |
| `LOG_LEVEL` | `debug` | `production` switches zap to JSON prod logger |

## Endpoints

- `GET /health` — liveness/readiness check, used by the frontend's connection indicator
- `GET /` — welcome message
- `GET /swagger/index.html` — interactive API docs (see `docs/README.md`)
- `GET|POST /api/vehicles`, `GET /api/vehicles/:id`
- `GET|POST /api/missions`, `POST /api/missions/:id/upload`
- `GET|POST /api/telemetry`
- `GET|POST /api/alerts`

## What's not implemented yet

- **MAVLink ingestion**: `internal/mavlink/session.go` is a comment-only stub describing the intended MAVSDK-Go session lifecycle. `internal/mavlink/tunnel.go`'s `DecodeTunnelPayload` is a literal `panic("not implemented")` — it needs to port a `decode_tunnel()` function from a referenced (but absent from this repo) Python prototype `mavlink_scraper.py`.
- **WebSocket route**: `internal/realtime.Hub` is a fully working register/unregister/broadcast implementation, but `main.go` never registers a `/ws` route or feeds MAVLink data into `Hub.Broadcast`.

## Docs

Swagger/OpenAPI is generated from `@Summary`/`@Router`-style comments above each controller method in `internal/modules/*/controller.go` and the general API block above `main()` in `cmd/server/main.go`. To regenerate after changing annotations or adding new endpoints:

```sh
go install github.com/swaggo/swag/cmd/swag@latest   # once
swag init -g cmd/server/main.go
```

`./run.sh` at the repo root does this automatically if `swag` is on `PATH` or in `$(go env GOPATH)/bin`.
